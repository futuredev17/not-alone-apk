# Not alone. (你从来不是一个人)

> “对你来说这只是一个简单的 App，但它是由 1728 行代码和一个 17 岁的灵魂铸就的。”

## 💡 项目简介
`Not alone` 是一款基于 Flutter 开发的“情绪价值”应用（V1.0 版本）。
在这个快节奏的时代，它不仅仅是一个简单的闹钟或日历，更像是一个懂你的赛博伴侣。它会显示时间与天气，并在你需要时，提供温暖的早安语。

## ✨ V1.0 核心功能
*   **沉浸式 UI**：深色模式搭配毛玻璃（Glassmorphism）特效，界面极简，支持自定义背景。
*   **精准闹钟**：调用系统底层本地通知，支持自定义铃声与时间设定。
*   **天气联动**：接入高德天气 API（目前主要适配中国大陆地区），实时显示当前天气。
*   **情绪文案**：内置多句温暖人心的提示语，在闹钟响起时给予情绪安抚。
*   **日历导航**：底栏导航切换，支持查看当前日历。

## 🛠 技术栈
*   **框架**：Flutter & Dart
*   **UI/UX**：自定义 Widget、毛玻璃特效、响应式布局
*   **数据交互**：第三方天气 API 请求与 JSON 解析
*   **状态管理**：基于 Flutter 原生状态管理实现 UI 实时刷新

## 🚀 运行方式
1. 确保已安装 Flutter SDK 和 Android Studio。
2. 克隆本仓库：`git clone [你的仓库链接]`
3. 安装依赖：`flutter pub get`
4. 运行项目：`flutter run`
