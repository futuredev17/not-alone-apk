# 🌧️ Not Alone (不是一个人)

> “慢慢来，你还没有迟到，你只是在自己的时区里。”

**Not Alone** 是一个基于 Flutter 开发的、高度可定制的开源情绪陪伴闹钟。它的诞生源于一个很普通的痛点：一个人在异乡醒来时，那种深深的疲惫与孤独感。

这不仅仅是一个闹钟，这是给那些在日常生活中需要一点温暖的人，准备的一把“赛博雨伞”。

## ✨ 核心功能

- **⏰ 情绪闹钟**：支持自定义本地铃声，配合随机弹出的治愈系文案，把你温柔地叫醒。
- **🌤️ 实时天气与关怀**：接入高德天气 API。不仅显示温度，还会根据下雨、降温自动提示你带伞保暖。
- **📅 全球化日历**：支持中国、德国、美国等多国节日显示。我们尊重每一种文化，因为世界是相连的。
- **🌳 树洞匹配（规划中）**：完全匿名、双向授权匹配。和同频的人互相倾诉，没有真实姓名，没有追踪，只有纯粹的共情。
- **🎂 生日彩蛋**：每年只能修改一次的生日设置，在当天为你弹出一个专属的电子蛋糕。
- **🎨 深度自定义**：自由更换壁纸、铃声和主题颜色，打造你的私人空间。
- **🌍 双语支持**：中/英无缝切换，为出海做准备。

## 🛠️ 技术栈

- 框架：Flutter
- 语言：Dart
- API：高德天气
- 本地存储：shared_preferences
